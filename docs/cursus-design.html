Cursus, all screens

A complete design for every screen in the app, in the Ultraviolet Dusk palette. Use the toggle to see light and dark. Track and Active Run are always dark, as they are in the current app. Names, numbers and routes are sample content.

Design system

Same structure as before (terrain Block Profile, Pace Band, run-type calendar, semicircle countdown), new colour, name and type. The accent is violet and no longer orange, and nothing in the language refers to a time of day.

Run types

TEMPOEASYLONGREST

Violet is tempo, moss is easy, glacier is long. A separate ring marks today so run type and today never compete for one colour.

Calendar

Each day is a 32px rounded square with its weekday above. Filled means done, outlined means planned, dashed means rest, grey with a strike means missed. Today gets a ring. The selected day fills with ink (bone in dark), never violet, because violet is reserved for the next thing to do. The month scrolls sideways and the arrows jump a month.

Rules

One primary action per screen. Missed sessions are described neutrally. Dark mode is its own design, not an inversion: cards turn translucent with a hairline, shadows disappear, the violet lightens to #8A72FF and text accents use the pale #C9B8FF.

Active Run and Track stay dark for glare and battery. Motion is limited to the pace band sliding and the terrain filling in on completion.
