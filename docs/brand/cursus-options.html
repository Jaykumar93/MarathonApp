Cursus: logo and mascot options

Eight logo directions and six mascot directions. Each logo is shown on light, on dark, and as an app icon at three sizes, because a mark that only works large isn't a logo. Each mascot is shown with four expressions that match the reflection faces and run states. Every shape here is simple SVG, so it can be exported as is.

Logo directions

Palette: violet #6C4DFF, light violet #8A72FF, glow #C9B8FF, ink #0F1220, bone #F4F1EA. Wordmark is lowercase Bricolage Grotesque Bold.

Mascot directions

The mascot should never appear during a run. It lives on empty states, onboarding, the reflection step and personal bests. Expressions: easy, hard, max, resting, personal best.
