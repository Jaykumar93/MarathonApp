Cursus brand

Logo, app icon and the mascot Tor. Violet, a peak and a flag. Everything here is plain SVG in the same folder.

Logo

The mark is a peak with a flag: the climb of a training block and the finish line it ends at. The lockup sets the mark beside a lowercase wordmark in Bricolage Grotesque Bold. Outline the wordmark text in a design tool before it ships, so it doesn't depend on the font.

Tor, the mascot

Tor is a small, friendly mountain with a flag on top. Tor's shape is the logo mark with a face, so the two always feel related. Tor's moods match the effort faces in the run reflection.

EasyEmpty states, welcome, easy-run reflection
HardHard-effort reflection, tough weeks
MaxMax-effort reflection only
RestingPaused run, rest days, quiet notifications
Personal bestPersonal bests and finished plans
  • Use Tor for warmth: empty states, onboarding, reflection, milestones.
  • Never show Tor during a live run, in error states or anywhere a missed session is described.
  • Tor never talks. Text sits beside Tor, never in a speech bubble, and never sounds judging.
  • Tor always stands on the screen's ground line, so the feet never float.
