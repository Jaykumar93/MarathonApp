7. Notes

Track tab stays a dedicated, always-available entry point — independent of whether today has a scheduled session, so an unplanned/extra run is just as easy to start as a planned one.

Shoe/Gear and Export/Share are simple list/form patterns reusing the same listrow and card primitives shown above — not wireframed separately here to avoid repetition.

Adaptive plan-change prompt is a bottom sheet, not a full screen — same content structure as the Home banner (message + two equal-weight actions), just modal-presented from the Plan screen.

Ask coach chips appear wherever context is available (Post-Run Summary, Plan session detail) — tapping opens Coach with that run/session already loaded as context, rather than a blank chat.

All screens: tab bar present only on the 5 primary tabs; every other screen is a pushed stack screen with a back affordance in the top-left, omitted from these wireframes for clarity.
